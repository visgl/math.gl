References and credits

math.gl combines original vis.gl work, adapted numerical algorithms, vendored libraries, and optional datasets. We thank the authors who made these foundations available. Removing an npm dependency does not remove the provenance of code retained in the repository. Mathematical ideas, compatible APIs, copied source, and redistributed data are credited separately below.

Package source inventory​

Each published package includes LICENSE, THIRD-PARTY-NOTICES.md, and the applicable adjacent notices. The indexes link the full terms and describe what was adapted. Source headers identify upstream copyright holders and licenses.

Geometry and numerical foundations​

  • gl-matrix and three.js math sources are both implementation foundations and useful algorithm documentation. The shipped package notices identify the retained copyright holders.
  • CesiumJS core mathematics supplied the original culling and geospatial ports. The retained Apache-2.0 notices apply to those adaptations even where their interfaces have changed.
  • Stefan Gottschalk, Ming C. Lin and Dinesh Manocha, OBBTree: A Hierarchical Structure for Rapid Interference Detection: author-hosted paper, cited by the oriented bounding-box construction.
  • Mapbox earcut and Mapbox lineclip are the upstream triangulation and clipping implementations adapted for flat arrays. earcut also credits Simon Tatham's linked-list merge sort.
  • Steven M. LaValle, Planning Algorithms: quaternion interpolation, is a free mathematical reference cited in the quaternion kernel.

Mathematics and geodesy​

  • Charles F. F. Karney, Algorithms for geodesics, with GeographicLib documentation and source. math.gl incorporates attributed GeographicLib code and documents numerical qualification separately from the mathematical model.
  • John P. Snyder, Map Projections—A Working Manual, USGS PP 1395, and John P. Snyder and Philip M. Voxland, An Album of Map Projections, USGS PP 1453. These freely available references explain projection properties and conventions.
  • PROJ and proj4js supply documented formulas, directly adapted kernels and independent test references. Bernie Jenny, Bojan Šavrič, Tom Patterson, and the implementation contributors named in the Equal Earth source receive credit for that projection and its implementation.
  • EPSG Geodetic Parameter Dataset and OGC standards inform CRS definitions and serialization. Dataset terms and fixture provenance apply independently of math.gl's source-code license; support for a format is not certification.
  • S2 geometry, H3, A5, and Open Location Code define the cell systems exposed by DGGS adapters.
  • Jarke J. van Wijk and Wim A. A. Nuij, Smooth and efficient zooming and panning (2003): author-hosted paper. This is the algorithm cited by flyToViewport.

Segmented maps and unfolding​

See the projection bibliography and implementation credits for Peirce, Guyou, Gringorten, Berghaus, Goode, Boggs, Collignon and Waterman, including free sources and the specific D3 code used here. Projection invention, numerical implementation and interactive visualization are distinct contributions.

Nicolas “Nico” Belmonte inspired the myriahedral examples through his interactive demonstration and 2018 article. Our myriahedral background records the research lineage and implementation differences. The hinge and myriahedral code was developed independently of Nico's application code. Attribution does not imply that an unlicensed application can be copied.

Astronomy, light and sky​

These references describe the models used by Earth utilities. Source comments identify which equations or data each implementation uses; simplified display models are not full atmospheric or observatory-grade simulations.

  • Vladimir Agafonkin, SunCalc, and Louis Strous, solar-position equations.
  • Lukas Hošek and Alexander Wilkie, Skylight Modelling: model data distributed with the retained BSD notice.
  • Kevin Krisciunas and Bradley E. Schaefer, A model of the brightness of moonlight, and Andrew Crumey, Human contrast threshold and astronomical visibility.
  • Fritz Kasten and Andrew T. Young, Revised optical air mass tables and approximation formula.
  • Ferdinando Patat and collaborators, UBVRI twilight sky brightness at ESO-Paranal.
  • Francisco J. Ballesteros, New insights into black bodies, used for the documented stellar color-temperature approximation.
  • Eric Bruneton and Fabrice Neyret, Precomputed Atmospheric Scattering, a reference for the cloud/atmosphere model; see source comments for the approximations actually implemented.
  • Don Cross, Astronomy Engine, the planetary ephemeris runtime dependency.
  • JPL planetary physical parameters and USNO sidereal time supply physical and frame references.

Maintaining provenance​

For new adapted code, retain the upstream copyright and full license, record the source version or commit and material modifications, and include the notice in the published package. For datasets, record the upstream product, license, transformations and checksums. Scientific citations should identify the algorithm without claiming that a paper supplied source code. The repository's source-header check complements the package notice indexes; neither is a substitute for investigating the provenance of a new contribution.
