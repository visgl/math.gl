@math.gl/arrow

@math.gl/arrow provides utilities for working with binary columnar tabular data in the Apache Arrow format.

Usage​

import * as arrow from 'apache-arrow';
import {IndexedArrowTable, dehydrateArrowTable, hydrateArrowTable} from '@math.gl/arrow';

const arrowTable = arrow.tableFromArrays({name: ['alpha', 'beta'], score: [10, 20]});
const selected = new IndexedArrowTable(arrowTable, [1, 0, 1]);
selected.getValue(0, 'name'); // 'beta'

const payload = dehydrateArrowTable(selected.materializeArrowTable(), {copy: 'all'});
const restored = hydrateArrowTable(structuredClone(payload));
restored.numRows; // 3

Features​

FeatureSupportNotes
Indexed tables and vectors✅Filter, sort, slice, and gather rows while controlling materialization.
Schema validation and column renaming✅Preserve field metadata and compatible physical buffers.
Buffer copying and transport✅Explicit ownership, hydration/dehydration, and Arrow IPC.
Apache Arrow versions✅Optional peer supporting 17+; compatibility checks exercise 17–21.
Independent utility entries✅UTF-8, WKB/WKT, and physical GeoArrow descriptors work without Apache Arrow.
Projection and geographic calculationsSeparateUse @math.gl/geospatial; CRS metadata remains opaque here.

Why Arrow in math.gl?​

The vis.gl frameworks are designed to seamlessly produce, interchange, and process binary data in Arrow format. These shared utilities provide schema validation, column renaming, indexed table views, and table transport across those frameworks.

Geometry and GeoArrow processing are available in @math.gl/arrow/geoarrow.

Installation​

npm install @math.gl/arrow apache-arrow

Apache Arrow is an optional peer dependency, supporting version 17 and newer. Your application supplies one compatible Arrow installation. Importing the package root or /geoarrow requires Arrow. The /utf8, /geoarrow-utils, and /wkb subpaths do not load or require Apache Arrow. The development compatibility checks exercise Arrow 17, 18, 19, 20, and 21, plus IPC interchange between those versions.

Entry points​

ImportPurposeApache Arrow required
@math.gl/arrowArrow table/vector views, schemas, copying, and transportYes, 17+
@math.gl/arrow/utf8Byte-oriented string comparison and scalar parsingNo
@math.gl/arrow/geoarrowArrow-native GeoArrow adapters and processingYes, 17+
@math.gl/arrow/geoarrow-utilsPhysical descriptors, geometry kernels, codecs, tessellation, and streamsNo
@math.gl/arrow/wkbWKB/EWKB and WKT parsing, writing, and traversalNo

CRS metadata is retained opaquely; interpretation, projection, and geographic calculations belong in @math.gl/geospatial. Task scheduling is provided by the separate @math.gl/tasks package.

API reference​

APIPurpose
IndexedArrowTable and IndexedArrowVectorFilter, sort, slice, and reorder rows without immediately copying column values.
MappedArrowTableAdd string-keyed lookup while retaining indexed transforms.
Schema utilitiesValidate field structure and rename columns while retaining buffers.
splitArrowBuffersControl ownership of Arrow internal typed-array buffers.
Table transportHydrate/dehydrate column buffers or encode/decode full Arrow IPC.

The table views are read-only APIs, not deeply immutable snapshots. Treat their backing tables, index arrays, and maps as immutable while views are in use. Transport payloads are a math.gl protocol, not loaders.gl table wrappers.
