# Benchmarks

<!-- -->

Run the general math.gl benchmark suite in your browser. Start with **Core math** for vectors, matrices, and other core operations, or choose **All math.gl modules** for the broader suite.

Suite Core math (core)Run benchmarksStopReady

The benchmark runs in a worker so you can keep reading or stop it at any time. Nothing runs until you select **Run benchmarks**. Navigating away stops the worker; starting again clears the previous results.

Throughput is the number of operations completed per second; higher values mean faster execution. The tooltip on each result shows measurement variation. Compare the same operation on the same device and browser, with other intensive work paused. Throughput across different operations is not a measure of their relative quality, and browser timing is not an application performance guarantee.

These are the same benchmark definitions used by the repository's general benchmark runner. For coordinate transform comparisons between projection engines, use the [projection benchmarks](https://visgl.github.io/math.gl/next/examples/benchmarks).
