# A5Decoder

<p class="badges">
  <img src="https://img.shields.io/badge/From-v5.0-blue.svg?style=flat-square" alt="From v5.0" />
</p>

`A5Decoder` is the lightweight A5 geometry adapter exported by `@math.gl/dggs/a5`. It accepts hexadecimal tokens and `bigint` indexes, and implements the common [`DGGSDecoder`](./dggs-decoder) center, boundary, bounds, and token/index conversion methods.

For hierarchy, traversal, indexing, and other A5 operations, use the full [`a5-js`](https://github.com/felixpalmer/a5) API directly.
