# Task runtime API

[`TaskRunner`](https://visgl.github.io/math.gl/docs/modules/tasks/api-reference/task-runner.md) runs tasks in workers or locally and manages their resources. A task describes the calculation; the runner handles execution.

For a first example, start with [getting started](https://visgl.github.io/math.gl/docs/modules/tasks/developer-guide/task-runner.md). For methods, options, and lifecycle details, use the [TaskRunner reference](https://visgl.github.io/math.gl/docs/modules/tasks/api-reference/task-runner.md). See the [migration guide](https://visgl.github.io/math.gl/docs/modules/tasks/developer-guide/migration.md) for upgrade instructions.
