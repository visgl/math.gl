# Task runtime API

[`TaskRunner`](./task-runner.md) runs tasks in workers or locally and manages their
resources. A task describes the calculation; the runner handles execution.

For a first example, start with [getting started](../developer-guide/task-runner.md).
For methods, options, and lifecycle details, use the [TaskRunner reference](./task-runner.md).
The [migration guide](../developer-guide/migration.md) covers the earlier worker
functions, pools, and protocol helpers that are no longer public exports.
