# Projection scorecard

The S9 scorecard publishes source-matched accuracy, throughput, allocation, startup,
memory and bundle measurements for Node and three browsers. The current PR is
collecting its first complete snapshot; the required CI publication job retains
JSON and Markdown evidence without pooling environments or claiming an overall
SOTA ranking.

See [reproducible measurement commands and limits](./scorecard-methodology.md),
[accuracy domains](./accuracy-domains.md) and [live benchmarks](./benchmarks.md#live-benchmarks).
