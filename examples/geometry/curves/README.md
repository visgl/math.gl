# Curve flight lab

Run `yarn start` in this directory. Drag to orbit the 3D camera, scroll to zoom, or focus the
canvas and use arrow keys and +/−. Switch curves, change their vertical reach, reveal control
points or equal-distance samples, and compare direct parameter animation with approximate
arc-length traversal. Motion starts paused when reduced motion is requested.

Run `yarn start-local` inside the math.gl repository to use workspace source.
Run `yarn start` to use package exports or `yarn build` for a production bundle.
