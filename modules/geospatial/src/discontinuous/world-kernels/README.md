# World and regional projection kernels

Numeric kernels adapted from [d3-geo-projection 4.0.0](https://github.com/d3/d3-geo-projection/tree/v4.0.0/src),
by Mike Bostock and the D3 contributors, under the adjacent [ISC license](../D3-LICENSE.txt).
Each JavaScript file matches its upstream source filename except `d3-geo-raw.js`,
which is an independent spherical Lambert azimuthal equal-area formula used by Hammer.

Changes: display factories, D3 imports, and unused imports removed; shared numeric
epsilon tightened to 1e-12 for chart boundary sampling; Newton finite-difference
steps retained at 1e-6 independently of convergence tolerance. MapEngine supplies
chart-local clipping, bounded inverse fallback, source coordinates and layout. Regional factories also retain named coefficient tables.
Armadillo uses explicit domain clipping in place of the displaced hidden-y sentinel;
Hammer retroazimuthal adds a center inverse limit and chart-side branch handling.
No D3 runtime dependency is added. The projection formulas retain their historical
names; attribution to D3 concerns this implementation, not invention of the maps.

`integrate.js` retains the upstream adaptive Simpson integration attribution to
[scijs/integrate-adaptive-simpson](https://github.com/scijs/integrate-adaptive-simpson),
Copyright 2015 Ricky Reusser, under the retained [MIT license](./INTEGRATE-LICENSE.txt).

Independent numeric fixtures are generated by
`modules/geospatial/test/discontinuous/generate-world-reference.mjs` from a separate
installation of the pinned upstream package. Tests compare forward coordinates,
check chart-local inverse round trips, and exercise seam/pole geometry separately.
