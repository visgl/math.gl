# @math.gl/expressions

Parse and evaluate portable expressions with `@math.gl/expressions`. Use
`@math.gl/expressions/sql` to parse SQL queries and predicates.

Apache Arrow is an optional peer. Install it for `@math.gl/expressions/arrow`,
`@math.gl/expressions/arrow/worker`, `@math.gl/expressions/math`, and
`@math.gl/expressions/color`. The package root and SQL parser work without Arrow.

See the [expressions documentation](https://math.gl/docs/modules/expressions) for examples.
