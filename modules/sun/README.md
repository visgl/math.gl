# @math.gl/sun

[math.gl](https://math.gl/docs) is a suite of math modules for 3D and geospatial applications.

This module contains math to calculate sun positions.

For documentation please visit the [website](https://math.gl).

Sunlight color and intensity use derived Hošek–Wilkie 1.4a model data under BSD-3-Clause.
The complete copyright and license notice is included in `LICENSE-HOSEK-WILKIE`.
